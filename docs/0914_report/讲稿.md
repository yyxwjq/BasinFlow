# 0914 汇报讲稿：R + P → TS 流匹配修复与结果

配套文件：`BasinFlow_0914_TS_flow_report.pptx`（11 页）、`figures/`（4 张图）。

**一句话结论**：TS 侧从「退化的直接回归」改成真正的流匹配后，单次采样对齐 RMSD 中
位 **0.224 Å**，已越过中点桥（0.487 Å）与修复前直接回归（0.230 Å）；源噪声下压缩
**7.7×**，并首次具备真实采样方差与 best-of-N 能力。

---

## 汇报主线（为什么这样排序）

只报数字会被问「所以呢」。建议按 **方法 → 能力 → 任务** 三段推进：

1. **方法**：TS 模型原本不是流匹配，这是方法性缺陷，不是效果问题。
2. **能力**：修好后精度可比，但真正新增的是「一个输入 → 一个分布」，这才能支撑
   KMC 需要的多候选。
3. **任务**：TS 本身是可行的（两端点已知，起点就离目标近）；困难在 R→P 侧。

## 逐页要点

### P1 封面
- 标题：R + P → TS：从直接回归改成真正的流匹配
- 副标题直接写结论，让听众第一页就拿到数字。

### P2 问题：TS 模型并不是流匹配
- 退化两处：训练时间钉死在 `t = 0`；源是确定的中点桥，没有分布。
- 等价于拟合 `f(R,P) = TS − (R+P)/2` —— 这是直接回归。
- **可检验的判据**：把 `eval_num_steps` 从 1 调到 50，输出不变 ⇒ 没有积分。
- 为什么以前没发现：`docs/22` 论证过 R→P 用 `t=0` 更优，TS 侧照搬了这个结论，
  两篇文档各自自洽，合起来掩盖了问题。

### P3 修复：MolGEN 式随机源 + 全时间段监督
```
x0 = (R + P)/2 + σ·ξ      σ = 1.0 Å
t  ~ Beta(0.8, 0.8)
x_t = (1 − t)·x0 + t·TS
v   = TS − x0
```
- σ 不是「加噪声正则」，它让输运问题成立：源带 1 Å 噪声后，`x_t` 在 `t > 0` 时
  无法代数反解出 TS，网络必须学输运（`docs/22` 记录的泄漏）。
- 改动落在 4 个文件：数据与时间律、workflow（不再传死 `flow_time`）、
  评测（真积分）、评估工具（透传时间律）。

### P4 实验设置
- 数据：Transition1x aligned，9000 / 536，与 R→P **同一冻结划分**（basin 完全一致）。
- 模型：PaiNN 256×6，r_max 12 Å，endpoint-conditioned。
- 评测：全量 val 536 × 40 次采样 = 21440 样本，16 步积分。
- 资源：AMD2 单节点 32 核，训练+评测 3 h 16 min，exit 0。
- 基线与本结果同划分、同评测函数给出，因此**同口径可比**。

### P5 主结果（图 1）
三条证据同时在动：
1. loss 从中点回归水平降到地板以下；
2. 评测随训练持续改善；
3. **源基线（不含模型的灰线）始终不动** —— 若评测在漂，这条线也会动。

### P6 证据一：loss 说明了什么（图 2）
- 学习目标是 `v = TS − x0`，其中一部分是**任何模型都无法消除**的随机抽样。
  因此任何预测器的地板是 `mean|TS − x0| = 1.39`（实测 21327 个坐标），
  最优常数预测器就是 0。
- 模型降到 **0.206**，低于地板 ⇒ 它从 R、P 两端读出了系统性结构。
- **顺带修正 `docs/25`**：那里把地板写成 `σ√(2/π) = 0.80`，只算了噪声，
  漏掉 TS 偏离中点造成的系统性偏移，正确地板是 1.39。

### P7 证据二：与基线对比（图 3）

| 对照 | aligned 中位 | 性质 |
|---|---:|---|
| 中点桥（什么都不学） | 0.4870 | 基线 |
| 修复前直接回归 | 0.2300 | 退化的参数化（确定性一步映射） |
| **本次 flow，单次采样** | **0.2240** | **可部署** |
| 本次 flow，best-of-40 | 0.1236 | **ORACLE 上界** |

- 必须主动说明：best-of-40 选的时候用了参考 TS，推理时不知道哪次最好，
  它是诊断天花板，**不是成绩**。
- 修复前那 0.230 Å 精度接近，但它是确定性映射：没有分布、best-of-N 无意义，
  与本次不是同一种能力。

### P8 证据三：起点 → 产物（图 4）

| 量 | 中位 | 含义 |
|---|---:|---|
| 源 RMSD | 1.729 Å | 抽样起点离目标（**不含模型**） |
| total_motion | 1.640 Å | 积分过程中实际移动的距离 |
| aligned RMSD | 0.224 Å | 产物离目标 |

- 压缩 7.7×，且中间确实走了 1.64 Å ⇒ 是模型一步步搬过去的。
- 提醒：**别把源 RMSD 当基线**，基线是中点桥（无 1 Å 噪声），两者不可直接比较。

### P9 结论
1. **修复成立**：t 有分布、源有分布、采样是 16 步积分，field 非平凡性已有测试覆盖。
2. **精度可接受，能力是质变**：0.2240 优于中点桥，与修复前同级；新增真实方差与
   best-of-40（0.124）。
3. **任务可行**：起点本就离目标近，文献 0.1–0.2 Å 符合预期；R→P 的 2.03 Å 说明
   困难在 R→P 侧。

### P10 局限与口径（**必须一起讲**）
- 未弛豫、未做鞍点验证：`relaxation` / `saddle_validation` 都是 `not_run`，
  这些是几何差异，**不是物理验证过的事件召回率**。
- 只有单一口径：当前只报 proper-rotation（不允许镜像）；`docs/17` 要求双口径，
  与文献对比前需补 mirror-allowed 一列。
- 子集越小越乐观：8 事件时第 3 轮读 0.261 Å，64 事件同样第 3 轮是 0.390 Å。
- R→P 未重训，其 2.03 Å 是早期 40 epoch 结果，不同口径，不作为结论。
- `aligned` 只比内部几何，刚体平移/旋转误差不计入。
